# Проект по продуктовой аналитике

Отчёт по деятельности маркетплейса продаж товаров в сфере красоты

- Основной файл кода по отчёту - **Marketplace_analytics.ipynb**
- Текстовый файл отчёта - Report.ipynb

Данные представляют из себя 3 .csv файла - с информацией о клиентах (customers), о заказах (orders) и о содержании заказов (order_items)

Был проведен когортный анализ с расчетом ***retention*** у конкретной когорты. Затем определено наличие/отсутствие у продукта product/market fit с выдвижением гипотез решения проблем. После чего, при помощи фреймворка ICE была определена приоритетная гипотеза и основные метрики, на которые стоит обратить внимание при её решении (ключенвые, proxy, guardrail метрики).
